# 百度「站点属性 - LOGO」提交指引

本文档说明如何为 58 生态各子域在百度搜索资源平台提交站点 LOGO，
使 `site:xxx.58.tl` 的结果条目在标题左侧显示品牌标识。

> 目标变更：`openspec/changes/add-site-image-assets`（任务 6）。
> 依赖变更：`per-subsite-baidu-indexing`（站点验证必须先完成）。

---

## 一、为什么做这件事

搜索结果里的「图片位」有三个来源，优先级从高到低：

| 来源 | 说明 | 本变更对应动作 |
|------|------|----------------|
| 站点 LOGO | 站点属性里审核通过的品牌标识，展示在标题左侧 | **本文档**（E） |
| 页面缩略图 | 百度从页面抓取的内容图（排除二维码/头像/SVG） | 首页 hero 图、club 信息流缩略图、bid 拍品图（B-main / B-club） |
| 无 | 只显示标题 + 摘要 | —— |

站点 LOGO 的价值：**审核通过后覆盖全站结果条目**，不受单页有没有图片影响，
是投入产出比最高的一项（素材已随代码库生成，只需在平台提交）。

---

## 二、素材位置与规格

素材由 `tools/generate-seo-images.php` 生成（可改文案/配色后重跑）：

```bash
php tools/generate-seo-images.php
```

产出 `assets/images/logo/`，每个站点两个规格：

| 文件 | 规格 | 用途 |
|------|------|------|
| `{site}-logo-121x75.png` | 121×75 | 小尺寸 LOGO（列表/窄场景） |
| `{site}-logo-200x133.png` | 200×133 | 常规 LOGO |

对应关系：

## 三、提交步骤

### 1. 前置：站点已验证

百度搜索资源平台（<https://ziyuan.baidu.com/>）→ 用户中心 → 站点管理，
确认目标子域已出现在站点列表中且状态为「验证通过」。

未验证的站点先走 `docs/baidu-subsite-onboarding.md` 的验证流程。

### 2. 进入站点属性 - LOGO

```
搜索资源平台 → 站点管理 → 选中目标站点 → 站点属性
  → 找到「LOGO」区块 → 上传图片
```

### 3. 上传素材

- 首选上传 `{site}-logo-200x133.png`；
- 若平台提示尺寸不符，改用 `{site}-logo-121x75.png`；
- **图片要求（平台通用规则）**：
  - 清晰、主体居中、可识别度高的品牌标识；
  - 白底或透明底，不要花哨背景；
  - 不得包含二维码、联系方式、促销文案、第三方平台水印；
  - 与站点实际品牌一致（站点名称与 LOGO 主名对应）。

> 平台对尺寸/格式的要求可能随时间调整，**以页面上实时提示为准**。
> 若提示需要其他尺寸，改 `tools/generate-seo-images.php` 里的尺寸参数重跑即可。

### 4. 提交并等待审核

- 提交后状态会变为「审核中」，通常 **数个工作日**；
- 审核结果在「消息中心」通知；
- 通过后全站结果条目逐步生效，不是即时生效。

### 5. 常见被拒原因与调整方向

| 拒因 | 调整 |
|------|------|
| 图片不清晰 / 拉伸变形 | 提高字号重生成，避免缩放 |
| 含二维码或联系方式 | 已规避（生成脚本不含二维码元素） |
| 与站点名称不符 | 确认 LOGO 主名与站点标题品牌一致 |
| 图片过小 / 留白过多 | 改用 200×133，减少画布留白 |
| 站点内容质量不达标 | 先补内容与收录，再重申 |

## 四、验证

提交后 1~2 周，抽样搜索：

```bash
# 人工在百度搜索（本机 curl 抓不到 SERP 的 LOGO，需人工看）
site:www.58.tl
site:mall.58.tl
site:block.58.tl
```

判定标准：结果条目标题**左侧出现品牌标识**即生效。

记录格式建议（写回 `tasks.md` 任务 6.4）：

```
日期 | 子域 | 提交时间 | 审核状态 | 是否生效
2026-10-01 | www.58.tl | 2026-10-01 | 审核中 | 否
```

## 五、与页面侧改动的关系

站点 LOGO 与页面内容图**互补，不互斥**：

- 站点 LOGO 决定「标题左侧」的品牌标识；
- 页面内容图（首页 hero / club 缩略图 / bid 拍品图）影响「摘要右侧」的缩略图抓取；
- 两层都做，搜索结果条目才完整。

因此本变更同时包含两类改动，站点 LOGO 只是其中风险最低、最需要人工操作的一环。
