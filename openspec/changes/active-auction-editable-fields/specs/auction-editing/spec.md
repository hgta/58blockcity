## ADDED Requirements

### Requirement: 按拍卖状态分级的编辑权限

拍卖单的卖家编辑能力 MUST 按拍卖状态分级：

- `pending`（未开拍）：全部字段可编辑（起拍价、底价、加价幅度、起止时间、币种、接受城市、拍品描述；拍品本身不可更换——既有行为保持）
- `active`（竞拍中）：仅白名单字段可编辑——拍品描述、接受城市、落槌时间、底价
- `sold` / `ended` / `canceled`：全部字段不可编辑

非卖家 MUST 在任何状态下被拒绝编辑（既有归属校验保持）。

#### Scenario: 未开拍拍卖全字段编辑

- **WHEN** 卖家编辑一场 `pending` 拍卖并修改价格、时间、币种、城市与描述
- **THEN** 系统按既有 pending 校验规则保存全部字段，`current_price` 重置为新起拍价，状态按新开始时间重算

#### Scenario: 竞拍中拍卖仅白名单可编辑

- **WHEN** 卖家提交对 `active` 拍卖的修改，仅包含描述、接受城市、落槌时间、底价
- **THEN** 系统仅更新这四个字段，`current_price`、`status`、`start_price`、`bid_increment`、`currency`、出价记录 MUST 保持不变

#### Scenario: 竞拍中拍卖提交锁定字段

- **WHEN** 请求试图在 `active` 状态下修改起拍价、加价幅度或币种
- **THEN** 系统拒绝保存并返回明确错误，锁定字段值保持原样

#### Scenario: 已结束拍卖不可编辑

- **WHEN** 卖家对 `sold` / `ended` / `canceled` 拍卖发起编辑
- **THEN** 系统拒绝并提示拍卖已结束

### Requirement: 白名单字段的方向约束

`active` 状态下的白名单字段 MUST 满足方向约束（以数据库现值为基准）：

- 拍品描述：任意修改
- 接受城市：新城市集合 MUST 包含旧集合全部城市（只增不减）；旧值为空（不限城市）时新值须为合法城市集合
- 落槌时间：新时间 MUST 不早于现值（只延不缩）
- 底价：新底价 MUST 不高于现值（只降不升），且仍须满足底价 ≥ 起拍价的通用校验；原拍卖无底价（NULL）时 MUST 不允许新增底价（新增会抬高流拍门槛，对已出价买家不利）

违反方向约束 MUST 被拒绝并返回与约束一一对应的错误文案，不得静默修正。

#### Scenario: 接受城市只增不减

- **WHEN** 竞拍中拍卖现接受城市为「北京、上海」，卖家提交「北京、上海、广州」
- **THEN** 系统保存成功，收款城市变为三城

#### Scenario: 接受城市收紧被拒绝

- **WHEN** 竞拍中拍卖现接受城市为「北京、上海」，卖家提交仅「北京」
- **THEN** 系统拒绝并提示竞拍中的拍卖不能移除已开放的城市

#### Scenario: 落槌时间延长

- **WHEN** 卖家将竞拍中拍卖的落槌时间从现值延后 30 分钟
- **THEN** 系统保存成功，详情页轮询的倒计时自动按新时间刷新

#### Scenario: 落槌时间缩短被拒绝

- **WHEN** 卖家提交早于现值的落槌时间
- **THEN** 系统拒绝并提示竞拍中的拍卖只能延长落槌时间

#### Scenario: 底价下调

- **WHEN** 卖家将竞拍中拍卖的底价从现值下调且不低于起拍价
- **THEN** 系统保存成功，详情页底价进度按新底价计算

#### Scenario: 底价上调被拒绝

- **WHEN** 卖家提交高于现值的底价
- **THEN** 系统拒绝并提示竞拍中的拍卖只能下调底价

#### Scenario: 无底价拍卖新增底价被拒绝

- **WHEN** 竞拍中拍卖原本未设底价，卖家提交了底价
- **THEN** 系统拒绝并提示竞拍中的拍卖不能新增底价

### Requirement: 编辑入口覆盖竞拍中拍卖

「我的拍卖」页 MUST 在 `pending` 与 `active` 状态都提供「编辑拍卖」入口（进入统一编辑页 `create.php?edit=<id>`）；已结束状态不提供编辑入口。

#### Scenario: 竞拍中拍卖显示编辑按钮

- **WHEN** 卖家查看自己 `active` 拍卖的操作区
- **THEN** 页面展示「编辑拍卖」按钮并可进入编辑页

### Requirement: 编辑表单的状态感知渲染

编辑页 MUST 按拍卖状态渲染字段可用性：

- `pending`：全部可编辑字段可交互
- `active`：白名单字段可交互；锁定字段（起拍价、加价幅度、币种、开始时间、物品选择）渲染为不可交互并附「竞拍中不可修改」说明

服务端校验 MUST 为最终防线，前端禁用仅为体验优化。

#### Scenario: 竞拍中进入编辑页

- **WHEN** 卖家从「我的拍卖」进入一场 `active` 拍卖的编辑页
- **THEN** 描述、接受城市、落槌时间、底价可修改；起拍价、加价幅度、币种、开始时间、物品选择显示为锁定并带说明

#### Scenario: 已结束拍卖进入编辑页被回退

- **WHEN** 用户直接以 URL 访问已结束拍卖的编辑页
- **THEN** 系统重定向回「我的拍卖」页，不渲染编辑表单
