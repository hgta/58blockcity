# 城市门户 UI 打磨：页眉页脚统一、Hero 紧凑化、区块街景/互访圈优化

## 问题陈述

统一城市门户（`/city/{pinyin}.html`，`city.php` + `includes/city-portal-render.php`）上线后，与主站首页（`index.php`，近期已切换品牌橙主题）出现多处不一致与空间浪费：

1. **头部导航不一致**：门户 header 是「返回首页 / NFT交易 / 互访圈 / TOP200城市 / 我的区块」，首页是「区块交易 / BCT交易 / NFT头像 / 人气商城 / 互访圈 / 拍卖 + 登录/注册」，访客跨页时导航入口集合完全不同。
2. **Hero 缺人气值**：`cities.popularity`（已产生人气值）是平台核心指标之一，但 hero 统计区只有 4 块（全国排名/现有居民/开启区块数/基金余额），没有人气值。
3. **「该城暂无已命名的区块」空态信息量为零**：该文案含义是「这座城市在区块地图上还没有被用户购买/预留并自定义命名的地块」——对新访客不直观，且空态只有一行提示，浪费整块版面。用户设想「直接显示 9 区合并效果」，但 9 区合并大图会占满整屏，坪效反而更低。
4. **底部栏目不一致**：门户 footer 是 4 栏旧结构（公司简介/帮助中心等），首页是 5 栏深色 footer（关于/快速链接/帮助支持/关注我们二维码/联系我们），跨页视觉断层。
5. **互访圈网格缺角**：`cp-cgrid` 在 1200px 容器下为 4 列，当前取 6 个圈子 → 第二行只有 2 卡、右侧缺两个角，版面不平衡；且卡片未展示 `block_count`（互访圈区块数）。
6. **Hero 占用过高**：「{城市}区块城市 / 共建{城市}元宇宙」hero 区（padding 28px×30px、头像 104px、标题 30px）总高度 ~280px+，首屏被 hero 吃掉近三分之一，核心内容（资料卡/六模块）被推到折叠线以下，坪效低。

## 目标

对城市门户做一轮以「坪效 + 一致性」为原则的 UI 打磨：

- 页眉、页脚与首页完全同一套导航/栏目结构（同链接、同登录态逻辑、同视觉）。
- Hero 统计区增加「人气值」块（位于基金余额左侧，共 5 块），同时 hero 整体高度显著压缩（目标 ≤ 原来的 60%）。
- 区块街景空态从「一行灰字」升级为「9 区块概览」紧凑网格：每区一张小卡（区号 + 该区已开块数 + 深链进入该区地图），高度约 3 行小卡，不使用大图合并。
- 互访圈取满 8 个填满 2 行 × 4 列网格，卡片 meta 增加「N 个区块」。
- 所有改动只动渲染层与 CSS，六模块数据装配层仅微调（limit 6→8、新增分区统计查询），不涉及表结构变更。

## 范围

### In Scope

| 模块 | 内容 |
|------|------|
| 页眉统一 | `city-portal-render.php` header 替换为首页同款导航（6 子站 + 登录态按钮）；`city.php` 开启 session 并把登录态传入渲染上下文 |
| Hero 优化 | statgrid 4→5 块（新增人气值，取 `cities.popularity`）；`assets/css/city-portal.css` hero 系列尺寸压缩（padding/头像/字号/间距） |
| 区块街景空态 | `CityPortal::blocks()` 增加 9 区统计（`GROUP BY zone` 已开/总数）；空态渲染 9 区概览紧凑网格卡；有数据时维持现有 6 卡 + mini 区条 |
| 页脚统一 | 门户 footer 替换为首页同款 5 栏深色 footer（含二维码与版权行），HTML 对齐 `index.php` |
| 互访圈 | `Circle::getCirclesByCity` 取数 6→8；卡片 meta 追加 `block_count` 个区块；移动端网格降列适配 |
| 缓存 | 模板变更后清空 `city/cache/` 或等待 TTL(600s) 自然过期；`city/build-static.php` 全量重建可复用 |

### Out of Scope

- 不改六模块的数据口径与空态容错机制（`{ok,count,items,msg}` 结构不动）。
- 不改 `index.php` 首页本身（本轮只让门户向首页对齐）。
- 不引入 9 区合并大图/地图图片（维持无图轻量方案，图片缺失场景不做素材新增）。
- 不做登录态个性化内容差异（仅导航按钮文案/链接随登录态切换，与首页一致）。
- 不动 `city/city.css` 的既有公共类（避免波及其它引用页），新样式全部收在 `city-portal.css`。

## 影响范围

- **修改文件**：
  - `city.php`（session_start + ctx 增加 `logged_in`）
  - `includes/city-portal-render.php`（header/footer/hero/区块街景空态/互访圈模板）
  - `classes/CityPortal.php`（`blocks()` 增加 `zone_stats`；`circles()` limit 6→8）
  - `assets/css/city-portal.css`（hero 紧凑化、5 列 statgrid、9 区概览卡、互访圈网格微调）
- **数据库变更**：无（`cities.popularity`、`blocks.zone` 均为既有字段）
- **运行时产物**：`city/cache/*.html` 需失效重建（TTL 自动或手动清理）

## 成功标准

1. 任一城市页 header/footer 与首页逐项一致（导航项、登录态按钮、栏目、二维码、版权行）。
2. Hero 统计区显示 5 块指标，人气值位于基金余额左侧；hero 总高度较改前下降 ≥ 30%（桌面端）。
3. 无命名区块的城市（如长沙）：区块街景区显示 9 区概览网格（A–H/Z 每区一卡，含该区已开块数与深链），整卡高度不超过现 6 卡区块街景区。
4. 互访圈 2 行 × 4 列无缺角；每卡显示「圈主 · 分类 · N 个区块」。
5. 全部城市页（含 6 模块各种空态组合）渲染无 PHP 错误；缓存重建后页面正常。
