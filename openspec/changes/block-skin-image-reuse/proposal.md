# 提案：区块皮肤图片复用

## 问题

管理区块皮肤（`block/block/manage.php`），选择"图片"类型时只能上传新图片，无法使用之前已上传的图片。用户需要在多个区块上使用同一张图（如品牌 logo）时，每次都要重复上传，造成文件冗余。

## 方案

在图片模式区域，上传按钮下方增加"从已有图片中选择"的图片库面板。列出 `block/assets/uploads/block_skins/` 目录下所有已有图片，用户点击即可选中复用，无需重新上传。

## 受影响文件

- `block/block/manage.php` — 增加图片库面板 HTML + JS

## 复杂度

低，单一文件改动，纯前端交互。
