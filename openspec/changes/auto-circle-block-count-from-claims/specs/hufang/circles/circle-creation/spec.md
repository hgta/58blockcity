## MODIFIED Requirements

### Requirement: "拥有区块总数"由手动填写改为自动计算

在创建互访圈时，"拥有区块总数"字段不再由用户手动输入，而是根据用户选择的所在城市，从 block 子站自动获取当前用户在该城市的已认领区块数并回填。提交时后端将再次校验并使用该计算值创建圈子。

#### Scenario: 正常创建互访圈
- **WHEN** 用户填写互访圈名称、选择所在城市并提交表单
- **THEN** 系统以该用户在该城市已认领区块数作为 `block_count` 创建互访圈

#### Scenario: 用户未选择城市
- **WHEN** 用户未选择所在城市即尝试提交表单
- **THEN** 系统返回错误提示"所在城市是必填项"，且不允许创建互访圈

#### Scenario: 前端回填失败但后端可兜底
- **WHEN** 用户提交表单但前端未能成功获取区块数
- **THEN** 后端 MUST 根据提交的城市名重新查询并计算已认领区块数，确保创建流程不中断
