## Purpose

当用户在 hufang 子站创建互访圈并选择所在城市时，系统自动从 block 子站读取该用户在该城市已认领的区块数量，并作为"拥有区块总数"回填到表单中，避免用户手动填写导致的数据不一致。

## ADDED Requirements

### Requirement: 根据城市和当前用户统计已认领区块数

系统 MUST 提供一种方式，根据当前登录用户 ID 与城市 ID，统计该用户在 `blocks` 表中 `status='sold'` 且 `city_id` 匹配的区块总数。

#### Scenario: 用户在所选城市有已认领区块
- **WHEN** 用户选择了所在城市且该城市存在其已认领区块
- **THEN** 系统返回的区块总数等于该用户在该城市所有 `status='sold'` 区块的数量之和

#### Scenario: 用户在所选城市没有已认领区块
- **WHEN** 用户选择了所在城市但该城市没有其已认领区块
- **THEN** 系统返回的区块总数为 0

### Requirement: 创建互访圈时自动填充区块数

系统 MUST 在用户于 `hufang/circles/create.php` 选择城市后，自动将"拥有区块总数"字段设置为该用户在该城市的已认领区块数，并在提交时使用该值创建互访圈。

#### Scenario: 用户选择城市后自动回填
- **WHEN** 用户在创建互访圈表单中选择所在城市
- **THEN** "拥有区块总数"输入框自动变为该城市的已认领区块数且仅只读展示

#### Scenario: 用户切换城市后重新计算
- **WHEN** 用户在创建互访圈表单中切换所选城市
- **THEN** "拥有区块总数"字段 MUST 更新为新城市的已认领区块数

## REMOVED Requirements

无。
