# help-site-layout — Delta Spec

## ADDED Requirements

### Requirement: 紧凑的页面标题条取代大 hero

帮助中心首页与搜索页 SHALL 使用紧凑的标题条（高度约 90px 级别），MUST NOT 使用占据首屏四分之一以上的大色块 hero；标题条 SHALL 包含页面标题与热门关键词，桌面端 MUST NOT 与头部搜索重复出现第二个搜索框。

#### Scenario: 首页首屏紧凑
- **WHEN** 桌面端打开帮助中心首页
- **THEN** 页面标题区高度不超过 120px（含热门词行），其下第一个内容区块（浏览分类）在首屏可见

#### Scenario: 搜索页复用同一标题条
- **WHEN** 打开搜索页
- **THEN** 使用与首页一致的标题条组件（而非内联覆盖 padding 的 hero），不出现尺寸异常的复用块

#### Scenario: 桌面端不出现两个搜索框
- **WHEN** 桌面端（宽度 > 860px）打开首页
- **THEN** 页面中仅头部一个搜索输入框可见，标题条内不再渲染重复的搜索表单

### Requirement: 移动端每页都可搜索

在宽度 ≤ 860px 时，帮助中心所有页面 SHALL 提供可用的搜索入口（页面内搜索框或头部展开的搜索区），MUST NOT 因隐藏头部搜索而导致某类页面无法搜索。

#### Scenario: 文章页在手机上可搜索
- **WHEN** 以 375px 宽度打开任一文章页
- **THEN** 页面上存在可见的搜索输入框，提交后进入搜索结果页

#### Scenario: FAQ 与术语表页在手机上可搜索
- **WHEN** 以 375px 宽度打开 FAQ 页或术语表页
- **THEN** 页面上存在可见的搜索输入框

### Requirement: 统一的页面骨架

所有帮助中心页面 SHALL 使用统一的页面标题区结构（标题 + 可选副标题 + 可选右侧操作）与统一的面包屑惯例；MUST NOT 通过在组件上内联 `margin`/`padding` 的方式覆盖标题区尺寸。

#### Scenario: 标题风格一致
- **WHEN** 依次打开分类页、FAQ 页、术语表页、搜索页
- **THEN** 各页标题的字号、间距、与内容区的距离一致（来自同一组 CSS 类）

#### Scenario: 面包屑惯例统一
- **WHEN** 打开任一非首页页面
- **THEN** 页面顶部显示面包屑；首页不显示面包屑

### Requirement: 首页信息架构与公共组件复用

帮助中心首页 SHALL 以「主列 + 侧列」两栏结构组织内容（桌面端），主列包含浏览分类、热门教程、最近更新，侧列包含 AI 助手入口与大家都在问；FAQ 折叠项与 AI 助手推广条 SHALL 由公共函数输出，避免同一段 markup 在多个页面重复维护。

#### Scenario: 首页两栏展示
- **WHEN** 桌面端（宽度 > 860px）打开首页
- **THEN** 内容呈现为主列与侧列两栏；AI 助手入口位于侧列

#### Scenario: 移动端降为单列且顺序合理
- **WHEN** 以 375px 宽度打开首页
- **THEN** 内容按单列顺序展示（分类 → AI 助手 → 热门教程 → 最近更新 → 大家都在问），无横向溢出

#### Scenario: 公共组件单一来源
- **WHEN** 修改 FAQ 折叠项或 AI 助手推广条的样式与结构
- **THEN** 只需改公共函数一处，`home/search/faq/article` 各页同步生效
