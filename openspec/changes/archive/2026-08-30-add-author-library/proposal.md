# 增加作者库功能

## 问题

商城商品以"图案设计"为核心卖点（T 恤、手机壳、帆布袋等印花商品），但目前商品详情页仅展示店铺与模特信息，无法体现"图案是谁创作的"。需要一个与模特库平行的**作者（Author）系统**：

- 后台管理作者档案（昵称、简介、性别/城市/星座、创作风格、社交账号、粉丝数、原创作品图集等）
- 商品编辑时可关联图案作者（1:1，可选）
- 商品详情页展示作者卡片，点击进入作者专属展示页
- 作者页聚合该作者的全部图案商品及原创作品图集
- 作者支持关注/点赞互动、粉丝数统计
- 发现页支持筛选（性别/城市/星座/风格/搜索）与排序

## 目标

1. **后台作者管理**：CRUD 作者档案，可关联站内用户（可选）
2. **商品-作者关联**：商品编辑页可选作者（1:1），商品详情页展示作者卡片
3. **作者专属页面**：展示基本信息 + 原创作品图集（后台录入）+ 关联商品 + 关注/点赞
4. **作者库发现页**：筛选（性别/城市/星座/风格/搜索）+ 排序（粉丝/人气/作品/最新）+ AJAX 加载更多
5. **互动**：关注（author_follows + follower_count）、点赞（author_likes + like_count）
6. **我的关注**：并入作者关注（tab 切换模特/作者）
7. **SEO**：作者页标题/描述/结构化数据 + sitemap + 百度推送

## 范围

**In scope**:
- `authors` 表 + `author_follows` 表 + `author_likes` 表
- `products.author_id`（ALTER 追加）
- `Author` 类（CRUD、关注/点赞、图集聚合、筛选排序、计数刷新）
- Admin 作者管理页（`mall/admin/authors.php`）
- 商品编辑页增加"关联图案作者"选择
- 商品详情页展示作者卡片
- 作者库发现页 + 作者详情页（`mall/author/`）
- 作者关注/点赞 AJAX
- 我的关注页并入作者（`mall/user/following.php`）
- 导航入口（header + 首页）
- 作者页 SEO 元数据 + sitemap + 百度推送

**Out of scope**:
- 多作者/联合作品（本期单一作者 `author_id`）
- 前台用户自助申请成为作者
- 作者审核流程
- 作者独立留言板（沿用站内信，仅关联站内用户时可用）
- 排行榜作者榜（可在后续 change 增加）
