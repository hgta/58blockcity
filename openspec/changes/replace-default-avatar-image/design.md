# 设计文档

## 总体思路

纯静态资产替换。默认头像的参考 URL 全站统一指向 `assets/images/default.jpg`，替换该文件即可全局生效，无需改动任何 PHP / JS / CSS。

## 视觉规格

- **风格**：中性人像剪影（浅色底 + 灰色人形头肩轮廓），无性别/年龄特征，通用专业。
- **格式**：JPG。
- **尺寸**：256×256（比原 128×128 更高清，兼容小尺寸显示的 2x 缩放；整个头像显示尺寸通常 ≤80px，128 亦够用，此处取 256 提升清晰度）。
- **体积**：约 10KB（纯色剪影压缩率高，不影响性能）。
- **无水印**：不含任何 AI 生成水印/品牌文字。

## 制作流程

1. 用 AI 生成中性剪影式默认头像底图。
2. 去除右下角水印（裁剪出剪影完整、水印不落入的区域）。
3. `sips` 缩放转 JPG 输出至 `assets/images/default.jpg`。

## 兼容性

- 引用 URL 不变（`assets/images/default.jpg`），无需上报/回填。
- `User::avatarUrl()` 默认兜底路径不变。
- 浏览器按 `.jpg` 扩展名 + `image/jpeg` 响应头正常解码，无缓存版本问题（文件名未变，CDN/浏览器缓存策略不新增风险）。
