# 提案：更换全站默认用户头像

## 问题

`assets/images/default.jpg` 是全站 45+ 处代码引用的默认用户头像兜底图（`/ User::avatarUrl()` 默认值、无头像用户展示等）。但该图实际是「58区块同城·头像市场」的宣传图（黑底绿边 + 文字），作为**用户默认头像**观感不佳，且带品牌文字，不宜用于用户个人头像占位。

## 方案

仅替换 `assets/images/default.jpg` 这一个文件，**不改任何代码**。新图为「中性人像剪影」风格：浅色底 + 灰色人形轮廓，通用、专业，适合任何性别/年龄的用户作为默认头像占位。

## 改动文件

| 文件 | 改动 |
|------|------|
| `assets/images/default.jpg` | 替换为新的默认头像图（256×256 JPG，10KB） |

## 备注

- 全站 45+ 个 `default.jpg` 引用点均使用同一 URL，替换单文件即可全局生效。
- 新图为统一默认头像，不涉及无头像用户的个性化区分。
