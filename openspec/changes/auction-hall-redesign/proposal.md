## Why

`bid.58.tl` 目前的界面是一个「商店货架」而非「拍卖场」：截止时间是直接打印的静态数据库字符串（无倒计时）、首页出价次数读的是「有无领先者」因此恒为 0 或 1 次、拍品卡与普通电商列表无差别。拍卖赖以成立的三条情绪引擎——时间压力、竞争感、稀缺仪式——几乎全部关闭，用户感受不到「有人在抢、快结束了、我领先还是被超越」。

## What Changes

- 将 `bid.58.tl` 内容区整体改造成**暗场聚光灯**视觉（数字资产 Drop 风格）：近黑舞台底 + 铜琥珀（价值）+ 落槌红（紧迫）+ 青柠绿（领先），颜色各司其职；与 BCT 交易所暗金同族但刻意区分，保留共享 header 与全站导航统一。
- **SHALL 新增秒级倒计时**：全站所有拍品展示位均带秒级倒计时，按剩余时间三档配色（正常 / <1h 橙 / <5min 红脉冲），且倒计时基于**服务端时间同步**。
- **SHALL 修正为真实统计**：出价次数、竞拍人数改为真实聚合（来自 `auction_bids`），新增「关注数」社会证明。
- **新增自动延时（防狙击）机制**：结束前 N 分钟内有人出价则顺延 M 分钟，带次数上限与总时长上限，复用现有惰性状态机（不改 `settle`）。
- **新增出价即时反馈与通知**：下一口价提示 + 快捷加价（+1 档 / +5 档 / 自定义）、「你已领先 / 你已被超越」状态、被超越时向原领先者推送通知。
- **新增关注/收藏**：登录用户可关注拍品，影响关注数与个人列表。
- **新增底价（reserve）进度可视化**：把已有但从未展示的 `reserve_price` 变成「底价未达 / 已过底价」进度。
- **重写首页为竞价大厅**：全场主推（LIVE 追光）、即将结束横向滑轨、排序筛选（即将结束/最新/出价最多/价格）、带倒计时与热度的拍品卡、刚落槌成交榜。
- **重写详情页为竞价台**：大图陈列 + 竞价面板（当前价/涨幅、倒计时、领先者、下一口价、快捷加价）、实时叫价流（时间倒序，**3 秒轮询**）、拍品信息与规则说明。
- **重写「我的拍卖」为双视角看板**：卖家看板（我的拍品 + 被出价状态）与我的竞价（领先 / 被超越 / 得标）。
- **性能修正**：修复 `getActiveAuctions` 的 N+1 查询，出价列表排序由「金额倒序」改为「时间倒序」以适配实时流。
- **非目标（明确不做）**：资金托管（保证金冻结 / 中标划转 / 违约没收）、WebSocket/SSE 实时推流、独立 cron 结算服务、代理出价（proxy bid）。

## Capabilities

### New Capabilities

- `bid/auction-hall-theme`: 拍卖站内容区暗场聚光灯视觉主题，含色彩 token 纪律、排版、组件风格、状态光环与响应式规则，并保持与共享导航兼容。
- `bid/auction-countdown`: 全站拍品倒计时的展示规范与服务端时间同步机制，含三档紧迫配色与逐秒自走、定时对齐的刷新策略。
- `bid/auction-lobby`: 首页竞价大厅，含全场主推拍品、即将结束滑轨、拍品卡（倒计时/真实出价次数/竞拍人数/关注数/状态光环）、排序筛选与刚落槌成交榜。
- `bid/auction-lot`: 拍品详情竞价台，含当前价与涨幅、领先者状态、下一口价与快捷加价、底价进度、实时叫价流（3 秒轮询）、拍品信息与规则说明。
- `bid/auction-bidding-mechanics`: 出价机制增强，含自动延时防狙击、真实出价/竞拍人数/关注数统计、关注与收藏、「被超越/领先/得标」通知。
- `bid/auction-my-board`: 「我的拍卖」双视角看板，卖家视角（我的拍品与出价动态）与竞价视角（领先 / 被超越 / 得标 / 已结束）。

### Modified Capabilities

- 无现有能力变更。拍卖站此前未在 `openspec/specs/` 下沉过 spec（`openspec/specs/` 现有 `bct`、`popularity`），本次为新增能力集。既有出价/结算/所有权转移逻辑的行为契约保持不变。

## Impact

- **数据库**：新增迁移 `init/migrate-auction-v2.sql`。`auctions` 增列 `bid_count`、`bidder_count`、`watch_count`、`final_price`、`sold_at`、`extend_count` 及自动延时参数；`auction_bids` 增列 `prev_bidder_id`（用于「被超越」通知）；新增表 `auction_watches(auction_id, user_id)`。
- **后端类**：`classes/Auction.php` — `placeBid` 内推延 `end_time`、递增计数、向原领先者发通知；`getBids` 排序改为时间倒序；新增 `getBidStats()`；`getActiveAuctions()` 修复 N+1；新增关注/统计相关方法。复用 `Notification::sendSystemNotify` 与惰性 `tick()`/`settleExpired()`，`settle()` 结算逻辑不改。
- **前端页面**：`bid/index.php`、`bid/view.php`、`bid/create.php`、`bid/my.php` 视觉重写；新增 `bid/assets/css/auction.css`、`bid/assets/js/auction.js`；`bid/includes/header.php` 引入子站级静态资源。
- **接口**：新增只读轮询端点（返回 `server_now`、当前价、出价次数、竞拍人数、关注数、剩余秒数、最近出价），供详情页 3 秒轮询。
- **依赖/基建**：无新增构建工具、无新增常驻服务、无第三方实时推送；仅 CDN 或本地静态资源。轮询为纯 AJAX。
- **无资金动账**：本次不接支付、不动用户余额，`currency` 仍为标签语义。
